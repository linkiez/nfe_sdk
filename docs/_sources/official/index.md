# Arquivo Bruto Oficial

## Escopo

Esta pagina organiza o acervo bruto preservado em `docs/_sources/official/`.

Os arquivos aqui mantidos sao os artefatos originais baixados de fontes oficiais, incluindo HTML, PDF, ZIP e outros formatos que servem como evidencia primaria para as conversoes e dossies do repositorio.

- Este acervo nao substitui a documentacao editorial de `docs/`; ele preserva a origem bruta para auditoria e reconversao.
