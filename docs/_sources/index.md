# Acervo Rastreavel de Fontes Capturadas

## Escopo

Esta area integra `docs/_sources` ao conjunto principal de documentacao do repositorio.

Ela concentra tres camadas complementares:

- acervo bruto oficial baixado e preservado para rastreabilidade;
- acervo Markdown convertido para leitura direta dentro de `docs/`;
- acervo extraido de ZIP quando os pacotes oficiais contem HTML ou PDF convertiveis.

## Pontos de entrada

- [Arquivo bruto oficial](./official/index.md)
- [Acervo Markdown convertido](./markdown/index.md)
- [Documentos oficiais do Portal Nacional da NF-e](../documentos-oficiais-portal-nfe.md)
- [Manifesto de downloads oficiais](../_meta/official-download-manifest.json)
- [Manifesto de conversao Markdown](../_meta/official-conversion-manifest.json)

## Estado atual

- Downloads oficiais arquivados: `704`
- Conversoes Markdown concluidas: `505`
- Falhas de conversao registradas: `4`

## Leitura recomendada

1. Comecar pelo [acervo Markdown convertido](./markdown/index.md) para leitura humana.
2. Abrir o [arquivo bruto oficial](./official/index.md) quando precisar conferir a origem original.
3. Usar os manifestos em `docs/_meta/` para rastrear URL, tipo de conteudo e status de conversao.
