# Conteudo Extraido de ZIP

## Escopo

Esta area concentra os documentos Markdown gerados a partir de arquivos que primeiro precisaram ser extraidos de pacotes ZIP oficiais.

## Pontos de entrada

- [Indice do acervo oficial convertido](../index.md)
- [Hub do Portal Nacional da NF-e](../www.nfe.fazenda.gov.br/portal/index.md)
- [Arquivo bruto oficial](../../../official/index.md)

## Cobertura atual

- Origem com conteudo extraido publicada nesta rodada: [Portal Nacional da NF-e](./www.nfe.fazenda.gov.br/portal/index.md)
- Exemplo convertido disponivel: [Alteracao de Schemas PL_004](./www.nfe.fazenda.gov.br/portal/PL_004/Alteração%20de%20Schemas%20PL_004.md)

## Observacoes

- Apenas HTML e PDF extraidos entram na conversao Markdown atual.
- Arquivos como XML e XSD podem permanecer extraidos no acervo bruto, mas nao sao promovidos para Markdown.
