# NFe

## Papel no conjunto documental

Este indice agrupa os artefatos de NFe e aponta a ordem de leitura recomendada para este dominio.

## Ordem de leitura

1. Consultar [Cobertura oficial de notas fiscais](../notas-fiscais/index.md) para a visao transversal baseada na base oficial consolidada.
1. Ler [Capacidades do SDK para NFe](./capacidades-sdk.md) para entender cobertura, lacunas e dependencias operacionais.
2. Consultar [Emissao de NFe](./emissao-nfe.md) para aprofundar o fluxo funcional e as evidencias publicas levantadas.
3. Voltar ao [catalogo geral de capacidades](../capacidades-sdk.md) quando for necessario comparar este dominio com NFC-e ou Manifestacao do Destinatario.
4. Descer para o [registro de fontes](../_meta/source-registry.md) quando a leitura exigir auditoria de proveniencia.

## Artefatos deste dominio

- [Emissao de NFe](./emissao-nfe.md)

## Dependencias externas recorrentes

- Certificacao digital para assinatura e validade juridica.
- Credenciamento e uso de servicos oficiais quando houver operacao real.
- Regras estaduais complementares alem da base nacional, ainda sem consolidacao completa nesta rodada.
