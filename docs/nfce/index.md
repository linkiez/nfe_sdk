# NFC-e

## Papel no conjunto documental

Este indice agrupa os artefatos de NFC-e e separa o fluxo nacional compartilhado do detalhe estadual por UF.

## Ordem de leitura

1. Consultar [Cobertura oficial de notas fiscais](../notas-fiscais/index.md) para a visao transversal baseada na base oficial consolidada.
1. Ler [Capacidades do SDK para NFC-e](./capacidades-sdk.md) para entender a cobertura principal do dominio e as lacunas atuais.
2. Consultar [Emissao de NFC-e](./emissao-nfce.md) para o fluxo nacional compartilhado.
3. Abrir [Matriz por UF](./uf-matrix.md) quando houver dependencia estadual, credenciamento local ou variacao operacional.
4. Voltar ao [catalogo geral de capacidades](../capacidades-sdk.md) para comparar o peso deste dominio no conjunto do SDK.
5. Consultar o [registro de fontes](../_meta/source-registry.md) quando a leitura exigir auditoria de origem.

## Dependencias externas recorrentes

- Credenciamento e portais estaduais especificos por UF.
- Regras de contingencia e disponibilidade que podem variar por autorizador.
- Complementos estaduais ainda nao consolidados em profundidade para as 27 UFs.
