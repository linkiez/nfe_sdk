# Matriz NFC-e por UF

## Objetivo

Mapear a cobertura documental das 27 UFs, destacando status, fontes consultadas, deltas especificos e lacunas abertas.

## Legenda de status

- `covered`: cobertura primaria suficiente para a UF.
- `covered-no-specific-delta`: cobertura nacional suficiente sem delta estadual confirmado.
- `partial`: cobertura incompleta ou com necessidade de complemento.
- `blocked`: fonte oficial indisponivel, restrita ou insuficiente no momento.
