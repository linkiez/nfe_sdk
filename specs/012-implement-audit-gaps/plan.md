# Implementation Plan: Implementação das Gaps do Roadmap Gap Audit (GAP-001–GAP-018)

**Branch**: `012-implement-audit-gaps` | **Date**: 2026-05-19 | **Spec**: [spec.md](./spec.md)

**Input**: Feature specification from `specs/012-implement-audit-gaps/spec.md`

## Summary

Implement all 18 normative gaps identified in `specs/011-roadmap-gap-audit/gap-report.md`.
The 15 implementable gaps are addressed in four priority bands: two hard blockers (access
key calculation, `hashCSRT`), followed by EPEC contingency and async batch retrieval, then
recipient query extensions, ICMS deferral events, XSD pre-validation, and e-CPF signing
support. The remaining three gaps produce documentation and watchlist artifacts only. All
new capabilities are additive to the existing ESM package surface — no existing export is
renamed or removed.
